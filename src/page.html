How dubplate works

1. Give it a list

Drop a spreadsheet (.csv, .xlsx), a text file with one song per line ("Artist - Title"), or a playlist (.m3u). You can also paste rows straight from Excel or Google Sheets. A Spotify export (e.g. from Exportify) works as it is.

2. Check what it found

  • Found: the exact song.
  • Best guess: a close match (a typo, a different spelling). Listen with ▶ to make sure.
  • Other version only: you asked for, say, the Extended Mix but only have the radio version or a remix. Shown so you know, but not copied unless you tick it.
  • Not found: not in your music folder. Download the missing songs as a CSV to keep a shopping list.

Every song has a ▶ button to listen first, and a menu to pick a different version you own.

3. Send them somewhere

  • Copy to a folder (e.g. your Traktor music folder): the files are copied exactly as they are.
  • Make a USB for the decks: one numbered playlist folder on the stick. Anything older CDJs/XDJs can't play (FLAC, Opus, ALAC, hi-res) is converted to AIFF or MP3; tags and artwork are kept. On the deck, browse the stick in its folder view.

Finding missing songs on Soulseek

If you use slskd (a Soulseek client), connect it in ⚙ Settings. Then 🔎 Find on Soulseek looks for the red and purple songs. dubplate picks the best file for each (the right version, good quality, someone who can send it soon) and shows it under the song, with other choices in a menu. Untick or change any, then click Download. When the downloads finish, dubplate reads your library again and they turn green, ready to copy. Add slskd's download folder under Also look in so they're found.

Settings

⚙ Settings (top of the page): your main music folder, other folders to also look in (a second drive, a downloads folder), and the Soulseek connection. Settings can only be changed on the computer dubplate runs on.

It remembers what it copied

Each destination has its own memory. Songs already copied to that folder (or that stick) are hidden, so after you've added missing songs to your library you can load the same list again and only the new ones are copied. A song you copied to your DJ folder still shows up for the USB, because the stick has its own memory. Click ✓ already copied to see them, and tick one to copy it again.

It never changes your library

dubplate only ever copies. It never moves, deletes or overwrites a file: if a file with the same name is already there it's left alone, and a different one gets " (2)" added. Its own memory and settings live in its settings folder.

Soulseek (slskd)

Connect your own slskd to look for missing songs on Soulseek. dubplate searches and shows you what it found; nothing downloads until you confirm.

How do I get an API key?
  1. Click (or type any 16 or more letters and numbers into the box above).
  2. Add these lines to slskd's options: in slskd's web page under System → Options → Edit, or in its slskd.yml file. If there's already an api_keys: line, add only the dubplate: part under it.
web:
  authentication:
    api_keys:
      dubplate:
        key: (your key)
        role: readwrite
  1. Save, and restart slskd if it asks.
  2. Come back here, click Test connection, then Save settings.
