Guides

A simple USB stick for the decks

The quickest way onto club decks. Each set becomes one folder on the stick, numbered in your order, and anything older decks can't play is converted on the way. You browse it with the deck's folder view.

Want BPM, key and waveforms on the decks?This kind of stick shows folders and files only. For a stick the decks read like one made in rekordbox, see Rekordbox USB.

Get the stick ready

Pioneer decks read FAT32 sticks. Most new sticks come formatted as FAT32 already; if yours doesn't, format it once.

Formatting erases everything on the stick.Copy off anything you want to keep first.
  • Windows: in File Explorer, right-click the stick → Format… → File system FAT32 → Start. Windows only offers FAT32 for sticks up to 32 GB; for a bigger stick use a formatting tool that offers FAT32.
  • Linux: in the Disks app, select the stick → the gear button → Format Partition… → choose For use with all systems and devices (FAT).
  • Mac: Disk Utility → select the stick → Erase → Format MS-DOS (FAT).

Make the stick

  1. Plug in the stick, load your list and check the matchesAs in Your first set.
  2. Choose 💾 Make a USB for the decksIn step 3.
  3. Pick the stickClick Browse… and choose the stick itself (on Windows a drive like E:\). Picking the stick's top folder keeps all your sets side by side.
  4. Name the set's folderPlaylist folder on the stick starts with your list's name. Use a different name for each set: Friday, Warm-up, Peak time.
  5. Choose what to convert toSee below. AIFF is the safe choice.
  6. Click Make USBThen eject the stick properly before you unplug it.

The stick then looks like this:

USB stick ├── Friday │ ├── 001 - Artist - First Song.mp3 │ ├── 002 - Artist - Second Song.aiff ← was a FLAC, converted │ └── 003 - Artist - Third Song.mp3 └── Warm-up └── …

What gets converted

Older Pioneer decks (CDJ-900, CDJ-2000, XDJ-1000, XDJ-RX and similar) can't play every file type. dubplate copies what they can play unchanged and converts the rest, on the stick only. Your library's files are never changed.

FileOn the stick
MP3, AACCopied as it is
WAV, AIFF (16/24-bit, 44.1 or 48 kHz)Copied as it is
FLAC, ALAC, Ogg, Opus, WMAConverted
Hi-res (above 48 kHz, or 32-bit)Converted

Songs the decks can't play become:

  • AIFF (lossless): full quality, bigger files. The default.
  • MP3 320 kbps (smaller): about a quarter of the size, and it sounds the same to nearly everyone on a club system.

Tags and artwork are kept either way.

Converting needs ffmpeg

ffmpeg is a free audio tool dubplate uses for converting. If it isn't installed, the page says so:

  • Windows: click Install ffmpeg now on the page (free, about a minute), then restart dubplate.
  • Linux: run sudo apt install ffmpeg (or your system's equivalent).

Without ffmpeg, MP3, WAV and AIFF files are still copied; only the files that need converting are left out.

At the deck

  1. Plug in the stick and choose it as the sourceUsually the USB button.
  2. Use the folder viewBrowse by folder, not the library or playlist view. Open your set's folder.
  3. Play in orderThe numbers keep the songs in your set's order.

Good to know

  • The stick remembers each set. Songs already in that set's folder are hidden next time, so you can top up a set. A different folder name starts a fresh set.
  • Your DJ folder doesn't count. Songs you copied to your laptop's DJ folder still show up for the stick; each place has its own memory.
  • Safe if you pull it out. Each song is written under a temporary name and only gets its real name once it's completely on the stick, so an interrupted copy never leaves a broken song behind.
