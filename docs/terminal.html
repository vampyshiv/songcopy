Using dubplate from a terminal

Everything the page does also works from a terminal. Handy for scripts, or if you'd rather type than click. You don't need any of this to use dubplate.

Commands

dubplate                                    # open the page (same as double-clicking)
dubplate find  friday.csv                   # check a list, copy nothing
dubplate copy  friday.csv ~/Music/Traktor   # copy to a folder
dubplate copy  friday.csv E:\ --usb         # a plain USB for the decks
dubplate copy  friday.csv E:\ --rekordbox   # a rekordbox USB: playlist "friday"
dubplate restore-stick E:                   # list a rekordbox stick's backups
dubplate restore-stick E: "2026-11-27 21.04.10"   # put one back
dubplate update                             # install the newest version

Songs it can't find are printed in red and saved next to your list as friday-missing.csv.

Options for copy

OptionWhat it does
--prefer flac|mp3|anyWhich format when you own a song in several (default flac).
--foldersKeep Artist/Album folders instead of one flat folder.
--numberPut the list order in front of file names: 001 - …
--playlistAlso write playlist.m3u8.
--strictDon't copy best guesses.
--any-versionCopy the version you have when the exact one isn't there.
--usbA plain USB for the decks: a numbered folder, converting what decks can't play.
--usb-format aiff|mp3What --usb converts to (default aiff).
--rekordboxA rekordbox USB: the destination is the stick, the list becomes a playlist.
--convert aiff|mp3|wav|noneWhat --rekordbox converts files older decks can't play to (default aiff).
--name NAMEThe playlist (or folder) name for --usb / --rekordbox. Default: the list's file name.
--recopyAlso copy songs already copied there before.
--dry-runShow what would happen, copy nothing.
--music PATHUse this music folder for this run.

Options for the page

OptionWhat it does
serve --no-browserStart without opening a browser.
serve --port 8766Use another port (if 8765 is taken).
serve --dest FOLDERStart with this destination folder filled in.
serve --host 0.0.0.0Allow other devices on your network; see Settings.

Updates

dubplate update            # install the newest version
dubplate update --check    # only say whether there is one
dubplate update --rollback # go back to the version you had
