Song lists dubplate understands

Almost any list of songs works: a spreadsheet, a playlist file, a text file or rows pasted from anywhere. Here's what dubplate reads and how to get a list out of the apps you use.

What you can give it

KindFilesWhat it should hold
Spreadsheet.xlsx .csv .tsvA header row with Artist and Title (or Song, Track, Name). Album and File (or Path) help if you have them. Any order.
Text file.txtOne song per line: Artist - Title, a file name, or a file's path.
Playlist.m3u .m3u8Any playlist, including ones made on another computer: dubplate matches by name, not by the old path.
Pasted(none)Rows copied from Excel or Google Sheets, or typed Artist - Title lines.

Getting a list out of other apps

Spotify

Use a free exporter such as Exportify: sign in, export the playlist as a CSV and drop that file on dubplate. Its columns work as they are.

Traktor, rekordbox, Serato, VirtualDJ, Engine

Export or save the playlist as an M3U / M3U8 playlist file (most DJ software offers this on a playlist's right-click menu) and drop it on dubplate. This is handy for moving a set from one computer to another.

A set written down anywhere else

Type or paste it, one song per line, as Artist - Title. Tracklists from a mix's description or a forum post usually paste straight in.

How songs are matched

dubplate reads your library's file and folder names. It handles the usual layouts, such as Artist/Album (Year)/Artist - Album - 07 - Title.flac from music managers like Lidarr, beets or Picard, and loose Artist - Title.mp3 files.

Spelling doesn't have to be perfect

Capitals, accents (Sigur Ros = Sigur Rós), punctuation, small typos, - Remastered 2011 and feat. Somebody don't stop a match.

Versions do matter

DJs care which mix they get, so dubplate does too:

  • (Original Mix), (Album Version) and no tag at all count as the same song.
  • Extended Mix = Extended Version.
  • Club Mix, Radio Edit, Live and any … Remix are different versions. If you ask for one and only have another, the song shows Other version only and isn't copied unless you tick it.

So write the version on your list when it matters: Artist - Title (Extended Mix).

When you own a song more than once

dubplate prefers the original studio album over live albums, compilations and remix albums, then the format you chose (FLAC or MP3).

A song is red but you know you have it?Matching reads names, not the tags inside files. Click Search the library myself… under the song, or compare your list's spelling with the file's name. If you added the song just now, click Rescan library at the top of the page.
