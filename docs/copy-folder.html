Guides

Copy a set to your DJ software

For DJing from a laptop. dubplate copies the files, exactly as they are, into the folder your DJ software uses. Then you add or import them the way you always do.

Copy the songs

  1. Load your list and check the matchesAs in Your first set.
  2. Choose 📁 Copy to a folderIn step 3, Where should they go?
  3. Pick the folderClick Browse…, open the folder and click ✓ Copy into this folder. Use your DJ software's music folder, or a new folder for this set inside it.
  4. Choose the options you wantSee below.
  5. Click CopyWhen it's done, the green box lists what was copied.

Options

Keep Artist / Album folders
Recreates your library's folders inside the destination (Artist/Album/song). Off: every song goes into the one folder.
Number files in list order
Puts each song's position in front of its name (007 - Artist - Title.mp3), so the folder sorts in your set's order. The number is the song's place on your list, so songs added later slot into their own place.
Also make a playlist file
Writes playlist.m3u8 into the folder, in your list's order. Most DJ and music software can import it as a ready-made playlist.

Then, in your DJ software

dubplate only copies files; your software still has to pick them up. Every program does this a little differently, so check its own help if this doesn't match:

  • Software that watches a music folder (Traktor's Music Folders, for example) finds new songs when it next checks that folder. Point it at the folder you copied into if it isn't already.
  • Software where you import files: drag the new folder, or the copied songs, into its library.
  • Import the playlist file if you ticked Also make a playlist file: most software can open or import playlist.m3u8, which gives you the set as a playlist in the right order.

Let your software analyse the new songs (BPM, key, beat grid) before you play them, as usual.

It remembers what it copied

Each destination folder has its own memory. Load the same list again later and songs already copied there are hidden, so after you've found the missing songs only those are copied. Click ✓ already copied to see the others, and tick any you want copied again.

  • A song is offered again if you've deleted its copy.
  • Copying the same set to a different folder, or to a USB stick, starts fresh: each place has its own memory.
Nothing is ever overwritten. If a file is already in the folder, it's skipped. If a different file has the same name, the new one gets (2) added to its name. And your library itself is never touched.
