Get started

Install dubplate

dubplate is a single program. Download it, run it, and it opens in your web browser. There's no installer and nothing else to set up.

Windows

  1. Download itGo to dubplate's releases page and, under the newest release, download dubplate-windows-x86_64.exe.
  2. Put it somewhere handyYour desktop or Documents folder is fine. It's the whole program.
  3. Double-click itThe first time, Windows may show "Windows protected your PC", because dubplate isn't signed by a paid certificate. Click More info, then Run anyway. You only see this once, not after updates.
  4. Your browser opens dubplate's pageA small window opens as well. Keep it open while you use dubplate; closing it stops the program.

Linux

  1. Download itFrom the releases page, download dubplate-linux-x86_64. It runs on any 64-bit Linux.
  2. Install itIn a terminal: 
    install -m 755 ~/Downloads/dubplate-linux-x86_64 ~/.local/bin/dubplate
  3. Run itType dubplate. Your browser opens the page at http://localhost:8765. Keep the terminal open while you use it; press Ctrl+C there to stop.
Already running?Running dubplate again while it's open just opens the page again. You can't start it twice by accident.

Where it looks for your music

On Linux dubplate starts with your Music folder. On Windows it looks for music on your home server first (see below) and otherwise asks. You can change this, and add more folders, any time in ⚙ Settings.

The first time, dubplate reads your whole library. That takes about a second for 25,000 songs on a local drive, longer over a network. After that it opens instantly and checks for new songs in the background.

Music on a home server (Windows)

If your music lives on a server and you copy to your Windows PC, dubplate finds the server by itself:

  • It tries the server that worked last time, then scans your network for about a second, then asks you. Type the server's name (like myserver.local) and it keeps working even when the server's address changes.
  • Windows asks you to sign in to the shared folder once, and remembers it.
  • It expects the music at \\server\home\Music. If yours is somewhere else, pick it in ⚙ Settings.

Updates

When a new version is out, dubplate shows a card at the top of its page with what changed. Click Update now: it downloads the new version, checks it hasn't been tampered with, keeps your current version as a backup, and restarts.

  • Changed your mind? Go back to … at the bottom of the page returns to the version you had.
  • dubplate checks for updates at most every 6 hours, and sends nothing else. Untick check automatically at the bottom of the page to stop that; Check for updates still works.
  • Your settings, your library list and what you've copied are kept through updates.
Alpha buildsUntil version 1.0, every release is a test build (an "alpha" or "beta"). Test builds update to newer test builds. Expect rough edges, and check anything important on your own gear first.
