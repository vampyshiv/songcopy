Reference

Help, questions and DJ words

Fixes for the things that most often go wrong, answers to common questions, and plain explanations of the words used in these guides.

Something's not working

Windows says "Windows protected your PC"

dubplate isn't signed with a paid certificate. Click More info, then Run anyway. You only see this the first time.

A song is red but I know I have it

dubplate matches file and folder names, not the tags inside files. Click Search the library myself… under the song, or check your list's spelling against the file name. If you added the song just now, click Rescan library.

A song is purple

You don't have the exact version on your list (for example the Extended Mix). Tick it to copy the version you do have, or pick another from its menu.

Songs I expected are hidden

They were already copied to that place before. Click ✓ already copied to see them, and tick any to copy them again.

The deck doesn't show my songs (plain USB)

Use the deck's folder view, not its library or playlist view, and a stick formatted as FAT32.

The deck doesn't show my rekordbox playlist

In dubplate, pick the stick's top folder (like E:\), not a folder on it. Use a FAT32 stick, and eject it properly before unplugging. On the deck, choose the stick as the source and open PLAYLIST, not the folder view.

A BPM shows half or double

Each song gets one tempo fitted to the whole song, as rekordbox's normal analysis does, so a mostly half-time song can read as half its tempo. dubplate can't correct a BPM by hand yet.

"couldn't write the stick"

The message says why. Usually the stick is full or write-protected. If anything had changed on the stick, the message names the backup that holds the library from before; restore it from the Rekordbox USB tab.

"ffmpeg isn't installed"

Needed only for the plain USB's conversions. On Windows, click Install ffmpeg now on the page. On Linux: sudo apt install ffmpeg.

"couldn't convert it - the file may be damaged"

The file couldn't be read. Try playing it on your computer; you may need a fresh copy of that song.

Windows can't find my home server

Check that you can open the server's music share (like \\server\home\Music) in File Explorer. On the server, the file-sharing settings and firewall must allow your network.

"Port 8765 is taken"

Something else is using that port. Start dubplate with dubplate serve --port 8766.

Soulseek: "didn't accept the API key"

The key in ⚙ Settings must match the one in slskd's options exactly, and slskd may need a restart after you add it.

Soulseek: "the API key is read-only"

Give the key role: readwrite in slskd's options.

Soulseek: downloaded, but the song is still red

The song is in slskd's download folder, which isn't one of your library folders. Add it under ⚙ Settings → Also look in.

Soulseek: "Nothing on Soulseek right now"

Nobody online is sharing it at the moment, or it's named differently. Try again later, or change how the song is written on your list.

Questions

Can dubplate damage my music library?

No. It only reads your library and copies from it. It never moves, renames, deletes or overwrites your files.

Does it change the tags in my files?

No. Converted copies on a USB stick keep their tags and artwork; your originals aren't touched.

Does it work with Serato, Engine DJ or Denon decks?

Copying to a folder works with any DJ software. The USB sticks are made for Pioneer CDJs and XDJs; a plain USB's folders may also play on other decks that read FAT32 sticks, but that isn't tested.

Is my music uploaded anywhere?

No. Everything happens on your computer. The only thing dubplate sends over the internet is its check for updates (and, if you set it up, requests to your own slskd).

Do I need rekordbox for a rekordbox USB?

No. dubplate writes the stick itself. You can still open the stick in rekordbox if you want.

DJ and audio words

BPM
Beats per minute: a song's tempo.
Key
The musical key a song is in. Mixing songs in compatible keys sounds smoother.
Beat grid
Markers on every beat of a song, which the deck uses for beat counting, sync and quantize.
Waveform
The picture of a song's sound on the deck's screen: an overview of the whole song, and a close-up that scrolls as it plays.
CDJ / XDJ
Pioneer DJ's media players, the decks found in most clubs. They play music from USB sticks.
rekordbox
Pioneer DJ's software for preparing music for its decks. dubplate can make the same kind of stick without it.
FAT32 / exFAT
Ways a USB stick can be formatted. Every Pioneer deck reads FAT32; newer ones also read exFAT.
Lossless
Audio with nothing removed: FLAC, ALAC, AIFF, WAV. Bigger files.
FLAC
A lossless format that's smaller than WAV or AIFF. Older decks can't play it.
AIFF / WAV
Lossless, uncompressed formats every deck plays. AIFF keeps tags and artwork more reliably.
MP3 320
MP3 at its highest quality (320 kilobits per second). Much smaller than lossless; on a club system most people can't hear the difference.
Extended Mix / Radio Edit
Versions of the same track. The extended mix has longer intros and outros for mixing; the radio edit is shorter.
Playlist file (M3U)
A small file listing songs in order. DJ and music apps can import and export it.
Soulseek / slskd
Soulseek is a network where people share music. slskd is a Soulseek client that runs in your browser.
API key
A password one program (dubplate) uses to talk to another (slskd).
