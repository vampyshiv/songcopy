Reference

Settings, folders and other devices

Where dubplate looks for music, how to use its page from your phone, and what it keeps on your computer.

⚙ Settings

Open ⚙ Settings at the top of the page.

Main music folder
The folder with your music. dubplate reads every song in it and its subfolders, and never changes anything there. Click Browse… to pick it.
Also look in
More folders that count as your library: a second drive, or the folder your downloader saves to. Add one with + Add a folder…; songs from it show that folder's name in front of their path.
Traktor
The folder with Traktor's collection.nml, for beat grids, keys and cue points on rekordbox sticks. Leave it empty to use Traktor's usual folder on this computer; if Traktor is on another computer, pick a copy of its collection. Tick Don't use Traktor to have dubplate analyse every song itself.
Soulseek (slskd)
The address and API key for slskd. See Fetch them through Soulseek.

Click Save settings when you're done. Settings can only be changed on the computer dubplate runs on, not from another device.

Using the page from your phone or another computer

Normally the page only opens on the computer running dubplate. To use it from a phone or laptop on the same network, start dubplate from a terminal like this:

dubplate serve --host 0.0.0.0

Then open http://computer-name:8765 (or the computer's address) on the other device.

  • Anyone on your network can then copy songs from your library into a folder on that computer, and browse its folders to pick where. They can't delete anything, and only songs from your library can be copied, never other files. Only turn this on at home, on a network you trust.
  • Settings (including testing the Soulseek connection), rekordbox sticks (making and restoring), updates and installing ffmpeg only work on the computer itself, opened as http://localhost:8765; on other devices those controls are switched off.
  • Behind a reverse proxy with its own web address, allow that name too: --allow-host dubplate.example.com.

What dubplate keeps

  • What it copied where, so the same list isn't copied twice to the same place.
  • Your settings, and a saved list of your library's songs so the page opens instantly.
  • Song analysis for rekordbox sticks, so each song is analysed once.
  • Decoded copies of Opus, WMA and other songs dubplate can't read by itself you've put on rekordbox sticks (as FLAC, so they can be analysed and converted). These take space, several times the size of the Opus file. When a song changes, its new copy replaces the old one; copies of songs you've since deleted or renamed stay until you delete the decoded folder inside dubplate's folder, which is always safe: copies are made again when needed.

These live in %LOCALAPPDATA%\dubplate on Windows and ~/.cache/dubplate on Linux. Deleting that folder resets dubplate.

Rekordbox stick backups are kept in ~/.local/share/dubplate/stick-backups on Linux, apart from the cache so cleaning tools leave them alone. On Windows they're in %LOCALAPPDATA%\dubplate\stick-backups, inside the folder above: resetting dubplate on Windows deletes your stick backups too, so move that folder somewhere safe first if you want to keep them.

Nothing extra is written into the places you copy to, apart from a rekordbox stick's own library and dubplate's small .dubplate folder on it.
