Reference

Settings, folders and other devices

Where dubplate looks for music, how to use its page from your phone, and what it keeps on your computer.

⚙ Settings

Open ⚙ Settings at the top of the page.

Main music folder
The folder with your music. dubplate reads every song in it and its subfolders, and never changes anything there. Click Browse… to pick it.
Also look in
More folders that count as your library: a second drive, or the folder your downloader saves to. Add one with + Add a folder…; songs from it show that folder's name in front of their path.
Soulseek (slskd)
The address and API key for slskd. See Fetch them through Soulseek.

Click Save settings when you're done. Settings can only be changed on the computer dubplate runs on, not from another device.

Using the page from your phone or another computer

Normally the page only opens on the computer running dubplate. To use it from a phone or laptop on the same network, start dubplate from a terminal like this:

dubplate serve --host 0.0.0.0

Then open http://computer-name:8765 (or the computer's address) on the other device.

  • Anyone on your network can then copy songs from your library. They can't delete anything, and only songs from your library can be copied, never other files on the computer.
  • Settings and stick restores still only work on the computer itself.
  • Behind a reverse proxy with its own web address, allow that name too: --allow-host dubplate.example.com.

What dubplate keeps

  • What it copied where, so the same list isn't copied twice to the same place.
  • Your settings, and a saved list of your library's songs so the page opens instantly.
  • Song analysis for rekordbox sticks, so each song is analysed once.

These live in %LOCALAPPDATA%\dubplate on Windows and ~/.cache/dubplate on Linux. Deleting that folder resets dubplate.

Rekordbox stick backups are kept separately, where cleaning tools leave them alone: %LOCALAPPDATA%\dubplate\stick-backups on Windows, ~/.local/share/dubplate/stick-backups on Linux.

Nothing extra is written into the places you copy to, apart from a rekordbox stick's own library and dubplate's small .dubplate folder on it.
